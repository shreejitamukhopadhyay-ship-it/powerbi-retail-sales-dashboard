# Retail Sales & Returns Dashboard

**Guided Power BI course project · Shreejita Mukhopadhyay**

I completed Maven Analytics' [Microsoft Power BI Desktop for Business Intelligence](https://www.udemy.com/share/1013gI3@_TUDN7FYJ-6JIdnc2KoLZrisfPacrb8_0UQ5uEroZdIwLEZojKRQfJ7yNYaR_fRYMg==/) course and built a multi-page dashboard using the AdventureWorks sample dataset.

## Project overview

The report explores sales performance, product and customer patterns, returns, and targets. It includes an executive overview, product and customer detail pages, a map, and exploratory pages using Power BI features such as a decomposition tree and key influencers.

## What I built

- Used Power Query to combine and transform sales files and prepare lookup tables.
- Added calendar attributes such as month, quarter, year, and period start dates.
- Modeled sales and returns with calendar, customer, product, and territory lookups.
- Created DAX measures for revenue, profit, orders, returns, return rate, prior-period comparisons, year-to-date results, rolling revenue, and target gaps.
- Arranged the measures into interactive executive, product, and customer report pages.

The project was completed as a guided course exercise. The course supplied the learning path and project framework; this repository describes Shreejita's implementation of that work. It is not client work, and the dataset and project brief are not original.
